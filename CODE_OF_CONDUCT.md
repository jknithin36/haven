# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be welcoming, assume good intent, and keep feedback about the work, not the person. Harassment of any kind isn't tolerated.

To report unacceptable behavior, open a private report through the repository's **Security** tab ("Report a vulnerability") or contact the maintainers listed in the repository. All reports are reviewed and kept confidential.
